# Associate: VC fund manager demo

A clickable product demo on a Supabase backend. Associate screens inbound deal flow against a fund's thesis, tracks portfolio companies from public signals, and drafts LinkedIn posts and website updates. The design follows `Associate.dc.html` from Claude Design.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/associate-demo.html, one self-contained file
```

The build is a single HTML file with scripts, styles, fonts and logos inlined. You can open it straight from disk or send it to someone. It needs internet, since its data comes from Supabase.

## Pages

| URL | What it shows |
| --- | --- |
| `#/` | Landing page, and the demo's hub: its top bar links Home and Dashboard. `#how` and `#access` jump to its sections |
| `#/demo` | The app with the 9-step guided tour, from a fresh state |
| `#/app` | The dashboard: the app without the tour. `#/app/deals`, `/portfolio`, `/public` and `/thesis` open a module |

"Associate" at the top of the app's sidebar returns to the landing page.

While presenting, use ← and → to step through the tour. When the tour is closed, chips in the bottom right offer "Guided tour" and "Reset demo".

Everything you do in the demo is saved, and everyone who opens it shares the same data. Opening `#/demo`, "Reset demo" and "Start over" put it back to the start, for everyone.

Add `?fund=Name` before the `#` to run the demo under another fund's name, for example `associate-demo.html?fund=Acme%20Ventures#/demo`.

## Data

Company names, logos, websites and descriptions come from the public Techstars portfolio. It is searched through the site's public Typesense index; the raw pulls are in `data/`. Claude Haiku agents drafted the enrichment in `data/enriched/`, which was then cleaned up by hand into the demo's seed, now in the `demo_seed` migration. Everything else is invented: the fund, rounds, scores, metrics, events and posts. Pilot Ventures is a fictional fund. The three former portfolio companies under Portfolio → Former (Carrowmere, Brindlewick and Tolvane) are fictional too, names included, so no real company is shown as acquired or shut down.

The demo's today is fixed at Sep 23, 2026 (`TODAY` in `src/config.ts`). Timeline dates, "4 weeks ago" and which companies count as quiet (no public update in 4+ weeks: hylosense, Profit Optimizer, Reeler, Harvest and Rhenari, under Portfolio → Quiet) are all counted from it.

Logo tiles are generated by `npm run logos` (`data/build_logos.py`, needs Pillow). It writes `src/assets/logos/` and a review sheet at `data/logo_sheet.png`. The raw downloads in `data/logos_raw/` are not in git; each company's `logo_url` in `data/candidates.json` points to the original.

The early-access form on the landing page doesn't send anything yet.

## Backend

The data lives in the Supabase project `associate`. `supabase/migrations` holds the schema, the actions that touch several tables (invest, pass, invite to a meeting and reset) and the demo seed. There is no login yet, so row-level security lets anyone with the app read and change the demo fund, and nothing else. `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` point the app at another project, such as a local `supabase start`.

The project is on Supabase's free plan, which pauses after about a week without visits. The demo then shows an error until the project is restored from the Supabase dashboard.
