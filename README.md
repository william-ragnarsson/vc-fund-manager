# Associate: VC fund manager demo

A clickable product demo with no backend. Associate screens inbound deal flow against a fund's thesis, tracks portfolio companies from public signals, and drafts LinkedIn posts and website updates. The design follows `Associate.dc.html` from Claude Design.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/associate-demo.html, one self-contained file
```

The build is a single HTML file with scripts, styles, fonts and logos inlined. It works offline, and you can open it straight from disk or send it to someone.

## Pages

| URL | What it shows |
| --- | --- |
| `#/` | Landing page, and the demo's hub: its top bar links Home, Apply for funding and Dashboard. `#how` and `#access` jump to its sections |
| `#/demo` | The app with the 11-step guided tour, from a fresh state |
| `#/app` | The dashboard: the app without the tour. `#/app/deals`, `/portfolio`, `/public` and `/thesis` open a module |
| `#/apply` | The fund's apply page, as a founder sees it. A submitted application lands at the top of Deal Flow → Inbound, scored against the thesis as it is set at that moment |

"Associate" at the top of the app's sidebar and "Back to Associate" on the apply page both return to the landing page.

While presenting, use ← and → to step through the tour. When the tour is closed, chips in the bottom right offer "Guided tour" and "Reset demo".

The apply page is also step 2 of the tour. "Demo: fill in an example" fills it with a fictional company, and after submitting, "See it in the dashboard" opens the new application in Deal Flow. Scoring is a deterministic stand-in in `src/apply/screen.ts`, so a rehearsed demo gives the same result every time.

Add `?fund=Name` before the `#` to run the demo under another fund's name, for example `associate-demo.html?fund=Acme%20Ventures#/demo`.

## Data

Company names, logos, websites and descriptions come from the public Techstars portfolio. It is searched through the site's public Typesense index; the raw pulls are in `data/`. Claude Haiku agents drafted the enrichment in `data/enriched/`, which was then cleaned up by hand into `src/data/seed.ts`. Everything else is invented: the fund, rounds, scores, metrics, events and posts. Kittiwake Ventures is a fictional fund.

Logo tiles are generated by `npm run logos` (`data/build_logos.py`, needs Pillow). It writes `src/assets/logos/` and a review sheet at `data/logo_sheet.png`. The raw downloads in `data/logos_raw/` are not in git; each company's `logo_url` in `data/candidates.json` points to the original.

Neither form sends anything: the early-access form on the landing page and the apply page both stay in the browser, and a chosen deck is never read (only its file name is kept).
